% Source: C++ Interview Prep -- Reading & Practice Plan (Sep 27, 2026)

Short-term review for C++ developer internship season, not HFT-core depth. The goal is recall speed
and explaining things under pressure, not learning them for the first time. About 2 weeks: reading
front-loaded in week 1, practice in week 2.

separate ``solid'' from ``clearly current.''

\subsection*{Practice Methods}
\begin{itemize}
  \item \textbf{Anki}: one card per gotcha, not per topic. Skip anything that is already instant recall.
  \item \textbf{Explanation drills}: explain each major topic out loud in under 60 seconds, from memory.
    If it doesn't come out clean, that's a gap: re-read the item, don't just re-skim.
  \item \textbf{Micro-exercises}: rewrite 5--10 LeetCode solutions (\code{map} $\leftrightarrow$ \code{unordered_map}
    with a justification; manual loops $\to$ ranges pipelines); write a small template from scratch
    (generic \code{clamp}, stack); run a missing-virtual-destructor bug under a sanitizer.
  \item \textbf{Mock questions}: add to the running list in \S\ref{sec:gotchas} while reading and self-test
    cold a day or two later.
\end{itemize}

\textit{Note:} if a target role's codebase is pinned before C++20, ask the recruiter whether ranges are worth the time.
